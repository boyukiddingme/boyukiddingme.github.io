# Boyu Portfolio — Editorial Version

This is a completely separate website from the Geography project.

## Files

- `index.html`
- `styles.css`
- `script.js`
- `assets/noise.png`

## Before publishing

Search `index.html` for:

- `YOUR-USERNAME`
- `hello@example.com`
- `href="#"`

Replace those with your actual GitHub profile, preferred public email and project links.

## Preview locally

```bash
cd boyu-portfolio-editorial
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## GitHub Pages

Upload the contents of this folder to the repository you want to use for GitHub Pages.

If it is your personal site repository, name the repo:

```text
YOUR-USERNAME.github.io
```

You can then connect an `is-a.dev` subdomain afterwards.
